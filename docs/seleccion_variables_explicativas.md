# Selección de variables explicativas: controles, mecanismos y heterogeneidad

- Periodo del panel de minería: 2006–2014.
- Unidad de observación: municipio-año.
- Objetivo: Identificar y documentar variables relevantes para analizar la relación entre minería y producción agrícola, considerando su posible papel como controles, mecanismos de transmisión o fuentes de heterogeneidad del efecto.
- Criterio de uso: La inclusión de una variable en esta tabla no implica incorporarla como control en la especificación principal. Su uso dependerá de su papel causal, disponibilidad temporal y variación dentro de los municipios.
